전체 기록 (모든 입력자)

이름 편집
화면에 보이는 이름을 마음대로 바꿀 수 있습니다. 이 기기에만 저장됩니다.
각 항목의 제목은 목록의 ✎ 버튼으로 고칩니다. 고친 내역은 기록으로 남습니다.
입력 항목 편집
기록 입력창의 칸을 더하거나 뺍니다. "선택지"는 한 줄에 하나씩 적으면 입력할 때 목록에서 고를 수 있고, 직접 적어도 됩니다. 시트에 연결돼 있으면 다른 분들 입력창에도 반영됩니다.
화면 구성
메인 화면의 구역을 보이거나 숨기고, 조건에 맞는 기록만 모아 보는 구역을 새로 만듭니다. 이 기기에만 적용됩니다.
앱으로 설치
홈 화면에 달리기 아이콘으로 추가해 앱처럼 쓸 수 있습니다.
안드로이드·PC 크롬: 주소창 오른쪽 설치 아이콘 또는 브라우저 메뉴 → "앱 설치/홈 화면에 추가"
아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
Google 시트로 보내기 (단방향)
기록이 입력될 때마다 시트로 전송만 합니다. 이 앱은 시트에서 다른 사람의 기록을 읽어 오지 않으므로, 각 기기에는 그 기기에서 입력한 것만 보입니다. 연결하지 않으면 이 기기에만 저장됩니다.
다른 분들이 설정 없이 쓰게 하려면 아래 공유 링크를 보내 주세요. 링크를 한 번 여는 것만으로 시트 전송이 설정됩니다.
전체 보기 (비밀번호)
시트에 모인 모든 입력자의 기록을 불러와 이 화면에서 한꺼번에 봅니다. Apps Script에 정해 둔 전체 보기 비밀번호가 필요하며, 이 기기에는 저장되지 않습니다(앱을 닫으면 해제).
